# 玉山 3D 路線動畫

以 3D 互動地圖呈現玉山主峰單攻路線的動態動畫，靈感來自 Relive。

---

## 專案簡介

本專案是一個純前端的單頁應用程式，在衛星影像疊加 3D 地形的地圖上，以動畫方式重播 GPX 路線（依原始點序由 **A** 前進到 **B**）。畫面同步顯示目前的累積距離與模擬海拔，並提供播放／暫停控制。

---

## 功能特色

- **3D 地形渲染**：使用 MapLibre GL JS 搭配 DEM 高程資料，地形誇張倍率 1.5×
- **衛星底圖**：使用 ArcGIS World Imagery 衛星圖磚
- **路線動畫**：標記點沿 GPX 原始路線順序移動（不做鏡像回程補點），動畫全程約 40 秒
- **起終點旗標**：以紅色旗標標示 GPX 原始首點 **A** 與原始末點 **B**；若起終點重疊，會自動左右錯開避免重疊
- **鏡頭跟隨**：地圖鏡頭即時跟隨標記點，並自動朝向行進方向
- **數據儀表板**：即時顯示累積距離（km）與插值模擬海拔（m）
- **播放控制**：播放 / 暫停按鈕；播完後再按可重頭播放
- **沉浸體驗**：隱藏 MapLibre 預設操作元件，提供更簡潔的全螢幕畫面

## 檔案結構

```
show_my_route/
├── index.html    # 整個應用程式，含 HTML 結構、CSS 樣式與 JavaScript 邏輯
└── README.md     # 專案說明文件（本檔案）
```

所有功能皆集中在單一 `index.html` 中，無需建置步驟或後端服務。

## 使用方式

### 直接在瀏覽器開啟

```bash
# Windows（PowerShell / CMD）
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

或以任意靜態檔案伺服器提供服務，例如：

```bash
# Python 3
python -m http.server 8080
# 接著開啟 http://localhost:8080
```

開啟後地圖會自動載入，路線原始首末點會顯示紅色 **A/B** 旗標（上傳新 GPX 後也會同步更新），點擊畫面下方的 **▶ 播放** 按鈕即可開始動畫。

## 注意事項

- **網路連線必要**：地圖圖磚（衛星底圖、DEM 地形、字型）皆從外部 CDN 即時載入，離線無法使用。
- **無需 API Key**：目前使用的衛星圖磚（ArcGIS World Imagery）與高程圖磚（AWS Terrarium）均為免費公開端點，不需要任何 API 金鑰。
- **瀏覽器相容性**：需要支援 WebGL 的現代瀏覽器（Chrome、Firefox、Edge、Safari 等新版），舊版或 WebGL 停用的瀏覽器將無法顯示地圖。
- **路線資料為手動標注**：路線座標點為簡化的手動輸入資料，並非 GPS 軌跡，海拔資料亦為估算值，不代表精確高程。
- **沙盒環境限制**：若在 iframe 沙盒（如某些線上預覽工具）中開啟，地圖可能因安全限制而無法載入；建議直接以瀏覽器或本機伺服器開啟。
