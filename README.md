# 3D GPX 路線動畫

以 3D 互動地圖播放 GPX 軌跡動畫，靈感來自 Relive。

---

## 專案簡介

本專案是一個純前端的單頁應用程式，在衛星影像疊加 3D 地形的地圖上，以動畫方式重播 GPX 路線（依原始點序由 **A** 前進到 **B**）。畫面同步顯示目前的累積距離與模擬海拔，並提供播放／暫停控制。預設載入路線為 `gpx/Qixingshan.gpx`（七星山）。

---

## 功能特色

- **3D 地形渲染**：使用 MapLibre GL JS 搭配 DEM 高程資料，地形誇張倍率 1.5×
- **衛星底圖**：使用 ArcGIS World Imagery 衛星圖磚
- **GPX 路線動畫**：標記點沿 GPX 原始路線順序移動，動畫全程約 40 秒
- **起終點旗標**：以紅色旗標標示 GPX 首點 **A** 與末點 **B**；若起終點重疊，會自動左右錯開避免重疊
- **鏡頭跟隨**：地圖鏡頭即時跟隨標記點，並自動朝向行進方向
- **數據儀表板**：即時顯示累積距離（km）與插值模擬海拔（m）
- **播放控制**：播放 / 暫停按鈕；播完後再按可重頭播放
- **沉浸體驗**：隱藏 MapLibre 預設操作元件，提供更簡潔的全螢幕畫面

## 快速開始

由於 `index.html` 以 `fetch()` 載入 GPX 檔案，**必須透過 HTTP 伺服器開啟**，不支援直接以 `file://` 開啟。

```bash
# Python 3（在專案根目錄執行）
python -m http.server 5500
# 接著開啟 http://localhost:5500
```

或以任意靜態檔案伺服器提供服務，例如：

```bash
# Python 3
python -m http.server 8080
# 接著開啟 http://localhost:8080
```

開啟後地圖會自動載入，路線原始首末點會顯示 **A=綠色、B=紅色** 端點標記與旗標（上傳新 GPX 後也會同步更新），點擊畫面下方的 **▶ 播放** 按鈕即可開始動畫。

## 注意事項與已知限制

- **需要 HTTP 伺服器**：GPX 檔案透過 `fetch()` 載入，直接以 `file://` 開啟將因 CORS 限制失敗。
- **網路連線必要**：地圖圖磚（衛星底圖、DEM 地形、字型）及 CDN 套件皆從外部即時載入，離線無法使用。
- **無需 API Key**：衛星圖磚（ArcGIS World Imagery）與高程圖磚（AWS Terrarium）均為免費公開端點。
- **瀏覽器相容性**：需要支援 WebGL 的現代瀏覽器（Chrome、Firefox、Edge、Safari 新版）。
- **沙盒環境限制**：在 iframe 沙盒（如某些線上預覽工具）中開啟時，地圖可能因安全限制無法載入。
- **已知問題**：詳見 `issue-01.md` ～ `issue-05.md`，涵蓋動畫中斷、Turf 座標驗證等研究報告。
